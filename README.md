# Jollof Stock Local — releases

Installateurs Windows de **Jollof Stock Local**, l'édition hors ligne de Jollof Stock
(serveur et base de données sur le PC de la boutique, licence par code).

- Dernière version : voir [Releases](../../releases/latest).
- Le logiciel se met à jour seul à partir de `releases/latest/download/latest.json`.
- Les pré-versions (`vX.Y.Z-local.N`) servent aux tests et ne sont jamais proposées aux boutiques.

Construit par le workflow "Release Local (builder)" de `xelaktechsn/builder`.
